你是不是卡在這裡？

學台語卡住的地方，來來去去就那幾個。

而且多半不是你的問題。

要把台語寫下來的時候，卡得最明顯。

下面的問題，如果你問過、查過、或者被回答「你多練就好」——這一頁就是寫給你的。每一條先給答案，再告訴你完整的說明在哪裡。
第一組是「怎麼學都學不起來」，第二組是「唸出來好像不對」，第三組是「要寫下來的時候」。第一題最多人問，先看它。
卡住的人其實有兩種。
一種是只學過ㄅㄆㄇ的人：台語一開口就會，可是要寫成拼音，第一個字就寫不出來。這種卡得很明顯，自己知道。
另一種是已經學了臺羅的人：拼寫寫得出來、調號標得出來，於是相信「我手寫我口」。
可是臺羅記得下拼法，記不下高度——同樣標第 8 調的字，你唱出來不見得一樣高；標第 1 調的「伊」，你嘴裡唸的是中聲。這一種也卡住了，只是卡在自己看不到的地方。

「一」是第幾調？我查過好幾次，還是記不起來

不是你記性不好。是那個編號沒有東西可以掛。

你嘴裡的「一」是一個聲音；「第8調」是一個號碼。兩者中間沒有橋——所以每次查完，當下「好像」懂了，過幾天要標音，又對不起來是哪一調，只好再查一次。

把號碼換成音高，它就掛得上去了：

第8調就是中聲，平平的中音。
一（一個人的一）tsi̍t ＝ ㄐㄧㄊ+——跟「洞」tōng、「郡」kūn 同一個高度。
一（一生的一，文讀）it ＝ ㄧㄊ˙——頓，中聲上點一下就收。

兩個讀音裡，文讀的頓其實很少人搞錯——中聲半拍就收，辨識度高，一聽就分得出來。真正每次都對不起來的，是被編成「第8調」的那一個：它沒有形狀，只有號碼。

唸一次，你就不必再查了。編號要背，音高不用背——因為那個聲音本來就在你嘴裡。

看完整說明 → 調號怎麼換成音高

一、你覺得「怎麼這麼難」

這一組的共同答案只有一句：你不是背不起來，你是在背編號。編號沒有音高，所以只能死記；換成音高，就不必背了。

台語八個聲調，怎麼分辨？我一直背不起來

因為你背的是編號，不是聲音。

八字口訣（君滾棍骨群滾郡滑）要你先會唸那八個字——會唸的人不需要口訣，不會唸的人口訣也幫不上忙。
換個方式：高的是 So、中的是 Mi、低的是 Do，其餘四個在這三條線之間走。七格，會哼就會。

看完整說明 → 七個高度，一頁速成

台語變調規則好難，有沒有簡單一點的方法？

有。整套變調只有一張表，一句口訣。

低調個性，一個重點——高讓成中、中讓成低、低到底翻成降、頓也翻成降；降取起點成高、沈取終點成中。
你之所以覺得難，是因為現在要背一串編號（5→7→3→2→1→7），外加四條入聲專用條款。

看完整說明 → 變調：兩套規則，一個答案

入聲的變調（四變八、八變四）怎麼記？

不必記——它根本不需要專用規則。

收尾韻的字跟別的字走同一張表：頓 → 降、中 → 低。你會覺得要另外記，是因為那套系統把「韻母的收尾方式」當成了聲調。

看完整說明 → 收尾韻不必另立規則

怎麼判斷一個字是第幾調？每次都要想很久

因為那個流程從頭到尾不經過耳朵。

比對八個字 → 得到編號 → 套變調數字 → 對回符號。四個步驟，沒有一步需要開口。
改成標音高以後，這個問題會消失：你不是「判斷」它第幾調，你是「聽」它多高。

看完整說明 → 為什麼幾十年沒有人發現

二、你覺得「唸出來好像不對」

下面這幾題，多數人不會主動去想——因為要問出口，得先懷疑「標的那個可能不對」。
如果你會講一點台語，或者唸給長輩聽被糾正過，你大概已經撞到過其中一兩個：你的耳朵沒有錯。

台語的「第八調」到底要唸多高？

中聲。平平的中音，跟第7調同一個高度。

差別不在音高，在韻母有沒有收尾：郡 kūn 跟 滑 ku̍t 唱起來一樣高，一個拉著，一個收在 ㄎ。

如果你學了很久卻答不出這一題，那不是你的問題——編號本來就沒有告訴你音高。

看完整說明 → 調號怎麼換成音高

「排骨」「骨架」「排骨酥」的「骨」，為什麼聽起來不一樣？

因為它們真的不一樣——三個不同的高度。

排骨的骨是頓（半拍就收）、骨架的骨是降、排骨酥的骨是高。你沒有聽錯。

把辭典裡這三個詞的小喇叭按一次，自己聽。

看完整說明 → 一個音節，六個高度

台語的入聲到底有幾個調？兩個嗎？

「入聲」根本不是一種聲調。

-p、-t、-k 是韻母的收尾方式，跟唱多高是兩回事。收尾韻的字，七個高度照樣掛得上去；光是日常詞裡就聽得到六個。

看完整說明 → 收尾歸韻母管，高低歸聲調管

thinn（天）的 nn 要唸在哪裡？我唸出來跟長輩不一樣

鼻音在頭前，不是字尾。

-nn 不是一個音，是一個開關——它讓聲母鼻化。所以 thinn 是 ㄊㄥㄧ，不是 ㄊㄧㄣ；kiànn（鏡）是 ㄍㄥㄧㄚ_，不是 ㄍㄧㄢ_。

字母排在後面，人就唸在後面——這不是你的錯，是寫法的位置。

看完整說明 → 字尾的 nn

字尾的 h（bah、beh、phah）是什麼音？

沒有音。把 h 拆掉，這個字沒有收尾。

嘴唇沒合、舌尖沒頂、舌根沒卡——只是短。這批字是頓調（肉、拍、八、桌、鐵）或中調（學 o̍h、白 pe̍h、食 tsia̍h）。

-p -t -k 是真的收尾，要留著；-h 不是。

看完整說明 → 字尾的 h

「四變八、八變四」算出來的，跟我唸出來的不一樣？

對，兩者確實不一樣。而且對不上的是規則，不是你。

「出名」的出實際唱降，規則算出來是第8調（中）；「木瓜」的木實際唱低，規則算出來是第4調（頓）。
實際走的一律是——頓 → 降、中 → 低，跟其他字同一張表。

看完整說明 → 變調：兩套規則，一個答案

台語的「伊」是第幾調？我聽到的好像不是高音

你的耳朵沒有錯。

用華語唸一次「伊」，再用台語唸一次——你的聲音移動了。華語的伊唱高，台語的伊唱中。

這個比對不需要你先會什麼，也不需要相信誰：唸兩次，差別自己會出來。

看完整說明 → 為什麼幾十年沒有人發現

第5調是不是就是「二聲」（往上揚的那個）？

不是。第5調是沈——先沉到最低，尾巴才往上勾。

華語的二聲是從中間直接上揚，沒有前面那一段沉。台語真正「直接上揚」的那一格是第9調，用在三連音的第一個字（紅紅紅、滑滑滑的頭一個）。

如果第5調占走了「二聲」這個名字，「紅紅紅」的第一個紅就沒有名字可以標了。

看完整說明 → 第5調不是升調

台語到底有幾個聲調？七個還是八個？

高度只有七個。八是編號，不是音高。

低、中、高、升、沈、降、頓——七格，全部在 Do、Mi、So 三條線之間。八個編號裡，第7與第8唱在同一格；差別在韻母有沒有收尾。（而第6調早就併進第2調了。）

三、你要把台語寫下來

會講不等於寫得出來，寫得出來也不等於寫對了。這一組是動筆的時候才會撞到的。

我學過臺羅，我手寫我口——寫下來的就是我唸的吧？

不一定。臺羅記得下拼法，記不下高度。

拼法是「用哪些字母」，高度是「唱多高」。臺羅把高度交給編號去代表——而編號本身沒有音高。
所以會出現這種事：同樣標第8調的字，你唱出來不見得一樣高；「伊」標第1調，你嘴裡唸的卻是中聲。你寫下去的是你學到的編號，不是你嘴裡的聲音。

檢查方法很簡單：把你標好的那句，照著標的高度唱一次。唱得出來，才算記下來了。

看完整說明 → 為什麼幾十年沒有人發現

我只學過ㄅㄆㄇ，沒學過台語拼音，要怎麼開始寫？

用你已經會的那套寫。ㄅㄆㄇ 不必重學。

台語比華語多出來的，是幾個聲母（ㆠ ㆣ 之類）、收尾韻（ㄅ ㄉ ㄍ ㄇ）、鼻化開關，加上低和中兩個華語沒有的高度。
其餘都跟你會的一樣。不是從零開始，是在你會的東西上補格子。

習慣英文鍵盤的人，也有漢語拼音版、美語拼音版——同一套聲調符號，三件外衣。

我要考閩南語認證，聲調的題目一直錯

錯的多半不是你的台語，是中間那道換算。

你嘴裡有的是聲音，考卷上要的是編號。兩者之間沒有橋，你只能靠死記；一緊張、一變調，就對不回去。
先把七個高度固定在耳朵裡——低、中、高、升、沈、降、頓——編號就變成最後一步的查表，而不是唯一的依據。

變調題尤其如此：照編號要背一串數字外加入聲條款，照高度只有一句「低調個性，一個重點」。
